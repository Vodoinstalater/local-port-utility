# Bundled Bore binaries

The application includes the official Windows CLI binaries from [Bore v0.6.0](https://github.com/ekzhang/bore/releases/tag/v0.6.0):

- `bore-x86.exe` — `i686-pc-windows-msvc`, SHA-256 `23a249d09987f14e114ea126dc19ed00654acf35f8169cbd0f575c8f656ea7c5`
- `bore-x64.exe` — `x86_64-pc-windows-msvc`, SHA-256 `01709c64fe2787cdc9a21d7030b0f08ad72dff0c36b7ecb72f4f667a55a34b4f`

Both hashes are for the release ZIP assets as published by the Bore project. The binaries are renamed for the app and are included under the terms in [Bore-LICENSE.txt](Bore-LICENSE.txt). The app uses the x86 binary for its x86 and ARM64 builds; the x64 binary is used for x64 builds.
